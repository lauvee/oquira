# Oquira

**Exploring Open Finance. Building in public.**

Oquira is an open-source project exploring Open Finance through financial technology, software engineering and applied research, with an initial focus on the Dominican Republic.

The project aims to demonstrate how financial data sharing, consent management and account aggregation could work through an experimental consumer application, simulated financial institutions and developer APIs.

## Vision

Explore and build accessible financial experiences that demonstrate the potential of Open Banking and Open Finance, while promoting technical knowledge, transparency and open collaboration.

## What are we building?

Oquira is being developed around three main components:

- **Consumer Application:** An experimental financial dashboard where users can explore aggregated accounts, balances and transactions.
- **Bank Simulator:** Simulated financial institutions providing synthetic financial data through APIs.
- **Developer Platform:** Experimental APIs and documentation for developers interested in exploring Open Finance integrations.

## Project principles

- Open source and public development.
- Transparency in technical and product decisions.
- Synthetic financial data only.
- Security and consent by design.
- Standards-oriented architecture.
- Learning and experimentation through practical engineering.

## Current status

**Phase:** Discovery and Research

We are currently investigating the Open Banking ecosystem, financial data standards, consent management, security architecture and the Dominican financial landscape.

## Technology

The initial technology direction includes:

- Java and Spring Boot
- React, Next.js and TypeScript
- PostgreSQL
- Keycloak
- Docker
- OpenAPI

Technology choices may evolve as the project progresses.

## Project disclaimer

Oquira is an independent experimental and educational project. It is not a bank, financial institution, regulated financial service or official Open Banking infrastructure.

It is not affiliated with or endorsed by any financial institution or regulatory authority.

All financial information used in the initial versions is synthetic. Oquira does not connect to real bank accounts.

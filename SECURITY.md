# Security Policy

## Supported Versions

Oquira is currently an experimental project under active development.

Security fixes are generally applied to the latest version available on the `main` branch. Older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately to the project maintainers.

Do not disclose vulnerabilities through public GitHub issues, discussions, or pull requests.

Until a dedicated security contact is established, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

If private vulnerability reporting is unavailable, contact the maintainers through a private communication channel before sharing technical details.

## What to Include

When reporting a vulnerability, please provide:

- A clear description of the issue.
- The affected component or version.
- Steps to reproduce the issue, if possible.
- Potential security impact.
- Any suggested mitigation or remediation.

Please avoid including real credentials, personal information, banking data, or other sensitive information in reports.

## Response Process

The maintainers will make reasonable efforts to:

1. Acknowledge receipt of the report.
2. Review and assess the reported vulnerability.
3. Investigate and determine its severity and impact.
4. Develop and validate an appropriate fix when necessary.
5. Coordinate responsible disclosure when applicable.

Response times may vary depending on project capacity and the complexity of the issue.

## Security Expectations

Contributors and users should:

- Never commit secrets, API keys, passwords, or private credentials.
- Use synthetic data for development, testing, and demonstrations.
- Avoid sharing real financial or personal information.
- Follow secure coding and dependency management practices.
- Report suspected vulnerabilities responsibly.
- Keep dependencies updated and review security advisories.

## Project Scope and Disclaimer

Oquira is an independent experimental and educational project.

It does not provide real banking connectivity, operate financial infrastructure, or represent a regulated financial service.

Security controls implemented in this project should not be interpreted as a guarantee of production readiness or suitability for handling real financial data.
